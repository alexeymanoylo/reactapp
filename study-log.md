## Окружение

- **Node:** v20.20.2 (LTS "iron"), npm 10.8.2 — через nvm.
- **Важно:** в новой сессии/терминале Node 10 может быть по умолчанию. Активировать:
  ```bash
  export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"; nvm use 20.20.2
  ```
- **Стек:** React + Vite (клиентский, без Next.js/SSR). JS/JSX (без TypeScript на старте).
- **Стили:** CSS Modules (пишем привычный CSS/BEM, классы изолируются автоматически).
- **Запуск dev-сервера:** `cd app && npm run dev` (послье активации Node 20).
- **Создание каркаса (правильная команда):** `npx --yes create-vite@latest app --template react`
  (без лишнего `--` перед `--template`, иначе создаётся не React, а vanilla-ts — проверено на практике).
- **Где код:** весь учебный код — в `app/`; документация (`react-blueprint.md`, `study-log.md`) — на уровень выше.

## Формат работы (правила ментора)

1. Учим React **руками**, а не теорией. Каждый шаг = маленькая задача + минимум объяснений «в лоб».
2. Вёрстку (HTML/CSS/BEM) пишет ученик, React-обвязку (JSX, компоненты, пропсы, состояние) — с подсказкой ментора.
3. После каждого шага ментор проверяет код, правит, объясняет «почему так».
4. Прогресс фиксируется в этом файле (фазы + чек-лист + лог), чтобы не потерять контекст при разрыве сессии.
5. НЕ учим сразу: Redux/Zustand, TypeScript, Next.js/SSR, ручной DOM (`querySelector`).
